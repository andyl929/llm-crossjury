Set up llm-crossjury

    API keys and subscriptions

    llm-crossjury sends your question to several AI vendors and compares the answers. To talk to a vendor it needs an API key from that vendor's developer console.

    • API key: you pay the vendor per use. Every run shows a cost estimate first, and a daily budget stops runaway spending.
    • Subscription: use an existing chat subscription through the vendor's official command-line tool instead of an API key. Pick it per model on the Compare page.

    A chat subscription does not include API access; API keys are billed separately by each vendor.

    Get an API key

    You need a key from at least one vendor. Open the vendor's key page, sign in, and create a key. Copy it: most vendors show it only once.

      Budget

      History

      Conversations are saved on this computer only, in your user data folder, readable only by your user account. Their text is sent only to the models you ask.

      When off, new conversations are kept in memory only and are lost when the server stops. Conversations saved earlier stay until you delete them.

      Memory

      In long conversations, a memory model writes short summaries of older turns, so each call sends a compact context instead of the whole transcript.

      Automatic: a fast model on a signed-in subscription (no extra cost), else the cheapest fast model with an API key.

      Upper bound on the context sent with one call; never more than the model's own window.
