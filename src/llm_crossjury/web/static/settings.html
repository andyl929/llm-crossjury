Welcome to llm-crossjury

    API keys and subscriptions

    llm-crossjury sends your question to several AI vendors and compares the answers. To talk to a vendor it needs an API key from that vendor's developer console.

    • API key (available now): you pay the vendor per use. Every run shows a cost estimate first, and a daily budget stops runaway spending.
    • Subscription (coming soon): use an existing chat subscription instead of an API key. This mode is not available yet.

    A chat subscription (for example a paid chat app plan) does not include API access; API keys are billed separately by each vendor.

    Get an API key

    You need a key from at least one vendor. Open the vendor's official key page, sign in, and create a key. Copy it; most vendors show it only once.

      Paste your key

      The key is stored on this computer only, in your user settings folder. It is never shown again after saving.

      Test the key

      The test asks the vendor for its list of models. It spends no tokens and costs nothing.

      Your spending limits

      These limits protect you from unexpected costs. Runs that could exceed them are refused before any call is made.

      These are the current defaults (read-only here).

      All set

      You can add keys for more vendors, replace or delete keys at any time under Settings, API Keys.
