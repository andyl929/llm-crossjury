Set up llm-crossjury

    Welcome

    llm-crossjury asks several AI models the same question, shows their answers side by side, and helps you combine them into one answer. First, connect at least one model.

    How do you want to connect models?

    Subscriptions have no per-call cost but use your plan's limits. API keys are paid per call, and you see the cost estimate before each run.

    Gemini works with an API key only: Google does not allow its consumer plans in third-party apps.

    Connect your subscriptions

    For each plan you have, install the vendor's tool and sign in once. The buttons run the vendor's official commands, only when you click; you can also run them yourself in a terminal. llm-crossjury never sees your password or sign-in token.

    Checking…

    Just installed it? If this page still says Not installed, restart llm-crossjury. Signing in by hand? Open a new terminal first, so the new command is found.

    Add an API key

    Create a key on the vendor's site, paste it here and save. The test lists the vendor's models; it costs nothing.

    Stored on this computer only, in your user settings folder. It is never shown again after saving.

        Budget

        Runs whose high estimate exceeds a limit are refused before any call is made. Amounts are in USD.

        History

        Conversations are saved on this computer only, in your user data folder, readable only by your user account. Their text is sent only to the models you ask.

        When off, new conversations are kept in memory only and are lost when the server stops. Conversations saved earlier stay until you delete them.

        Memory

        In long conversations, a memory model writes short summaries of older turns, so each call sends a compact context instead of the whole transcript.

        Automatic: a fast model on a signed-in subscription (no extra cost), else the cheapest fast model with an API key.

        Upper bound on the context sent with one call; never more than the model's own window.
